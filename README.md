# Cobblemon Alphas

A fully–data-driven alpha Pokémon ecosystem for Cobblemon 1.7.2

Cobblemon Alphas expands the wild world of Cobblemon with rare, powerful Alpha Pokémon, dynamic herd behavior, configurable spawning and datapack support!

This mod supports both Fabric and NeoForge environments.

![An Alpha Charizard](alpha_charizard.png)

## Features

### Alpha Pokémon

- Randomly generated Alpha Pokémon appear in the wild
- Larger size (configurable multiplier)
- Enhanced IVs
- Chance for hidden ability
- Mastered a tutor move
- Optional shiny chance boost
- Customizable per-species spawn definitions via datapacks
- Underground-specific alphas supported

### 🐾 Herd System

Some Alpha species can spawn with a small herd of related Pokémon:

#### ✔ Herd Following Behavior

Herd members naturally follow the Alpha in a loose formation.

#### ✔ Herd Panic & Fleeing

If the Alpha enters battle, herd members panic and scatter.

#### ✔ Herd Regrouping

Herd members turn back toward the Alpha and regroup around it

Then naturally resume following behavior

#### ✔ Herd Linking

Herd members persistently track which Alpha they belong to.
